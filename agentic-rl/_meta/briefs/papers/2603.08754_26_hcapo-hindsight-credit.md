# Bounded Brief: Hindsight Credit Assignment for Long-Horizon LLM Agents

- source card: `notes/26_hcapo-hindsight-credit.md`
- source type: original paper

## Extracted Brief

**事实 [PDF abstract, p.1]**: HCAPO 针对 long-horizon multi-step tasks 的 sparse reward，指出 GRPO 等 value-free 方法有 step-level Q-value 估计不准和 intermediate-state baseline misalignment 两个瓶颈。

**事实 [PDF abstract, p.1]**: 方法让 LLM 自身作为 post-hoc critic，通过 hindsight reasoning 细化 step-level Q-values，并用 multi-scale advantage 补足关键决策状态的 value baseline。

**事实 [PDF abstract, p.1]**: 在 WebShop、ALFWorld 等 benchmarks 上，HCAPO 相比 GRPO 在 Qwen2.5-7B-Instruct 上分别提升 7.7% 和 13.8% success rate。

**解释 [本项目判断]**: HCAPO 是 agentic RL 里 “LLM-as-critic / retrospective credit” 方向的核心卡，和 CARL/BEACON/GiGPO 形成互补。
