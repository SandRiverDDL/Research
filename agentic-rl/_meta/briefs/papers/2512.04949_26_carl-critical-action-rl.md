# Bounded Brief: CARL: Criticality-Aware Agentic Reinforcement Learning

- source card: `notes/26_carl-critical-action-rl.md`
- source type: original paper

## Extracted Brief

**事实 [PDF abstract, p.1]**: CARL 指出 multi-step agents 中 group-level policy optimization 假设每步贡献相同，但实际只有少数状态下的 action choices 决定 final outcome。

**事实 [PDF abstract, p.1]**: 方法用 entropy 作为 state criticality 的启发式代理，只给 high-criticality states 的 actions 分配 reward 并更新模型，排除 low-criticality actions。

**事实 [PDF figure 1, p.1]**: CARL 声称更新动作数减少 72%，同时性能提升 3.7%。

**解释 [本项目判断]**: CARL 是 GiGPO/BEACON 之外另一条 credit-assignment 路线：不是构造 step group 或 milestone，而是选择哪些 action 应该接收梯度。
