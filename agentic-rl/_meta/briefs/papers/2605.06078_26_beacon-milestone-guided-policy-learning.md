# Bounded Brief: Milestone-Guided Policy Learning for Long-Horizon Language Agents

- source card: `notes/26_beacon-milestone-guided-policy-learning.md`
- source type: original paper

## Extracted Brief

**事实 [PDF abstract, p.1]**: BEACON 识别 long-horizon language agents 的两个根因：credit misattribution，即正确早期动作因 terminal failure 被惩罚；sample inefficiency，即成功轨迹稀少导致学习信号接近消失。

**事实 [PDF abstract, p.1]**: 方法将 trajectories 按 milestone boundaries 分段，在 segment 内做 temporal reward shaping，并在 trajectory 与 segment 两个尺度估计 advantages，避免远端失败污染局部动作评估。

**事实 [PDF abstract, p.1]**: 在 ALFWorld、WebShop、ScienceWorld 上，BEACON consistently outperforms GRPO and GiGPO；长 horizon ALFWorld 上 92.9% vs GRPO 53.5%，effective sample utilization 从 23.7% 到 82.0%。

**事实 [PDF intro, p.1]**: 论文指出 GiGPO 依赖 repeated states 构造 step-level comparison groups，而 long-horizon tasks 中 state recurrence 会随任务推进变弱；BEACON 利用 milestone / phase structure 替代 repeated-state assumption。

**解释 [本项目判断]**: 这是 GiGPO 后续必须补的 credit-assignment 卡。它不是 survey-derived，而是 forward recall 从 GiGPO/credit-assignment 轴扩展出来。
