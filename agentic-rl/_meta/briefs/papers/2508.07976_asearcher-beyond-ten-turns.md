# Bounded Brief: ASearcher

Source: `papers/2508.07976-asearcher-beyond-ten-turns.pdf`

## Key Evidence

- [p.1-p.3] ASearcher is an open-source project for large-scale RL training of search agents; it targets long-horizon search with tool calls exceeding 100 turns and output tokens over 400k during training.
- [p.2] The paper states prior online RL methods often use turn limits `<=10`, which restrict complex strategy learning.
- [p.9-p.10] Fully asynchronous RL is used because long trajectories create severe straggler effects; asynchronous trajectory rollouts decouple tool-call waiting from model training.
- [p.11] ASearcher trains with GRPO; advantages are relative rewards across trajectories in each group.
- [p.11] Dynamic filtering removes queries where all responses have identical rewards and hence zero advantages.
- [p.11-p.13] Reward is sparse at trajectory completion; experiments compare Search-R1, R1-Searcher, DeepResearcher, WebThinker, WebDancer and others. ASearcher-Web-QwQ-v2 reports 58.7 Avg@4 on GAIA and 51.1 Avg@4 on xBench-DeepSearch.

## Classification

ASearcher is not a pure objective paper. It is core-with-infra-risk because the transferable contribution is fully asynchronous rollout/training for long-horizon GRPO agents, plus dynamic filtering, while a large part of the work is search-agent system/data engineering.
