# Bounded Brief: Group-in-Group Policy Optimization for LLM Agent Training

- source card: `notes/25_gigpo-agent-training.md`
- source type: original paper

## Extracted Brief

**事实 [PDF abstract, p.1]**: GiGPO 目标是把 group-based RL 扩展到 multi-turn LLM agent training；静态任务 reward 立即到达，而 agent-environment interaction 有 sparse/delayed reward，导致 step-level credit assignment 更难。

**事实 [PDF abstract, p.1]**: GiGPO 提出 two-level relative advantage：episode-level macro relative advantage 基于完整 trajectory groups；step-level micro relative advantage 通过 anchor state grouping，将相同 state 出发的 actions 组成 step-level groups。

**事实 [PDF abstract, p.1]**: 论文声称在 ALFWorld、WebShop 和 search-augmented QA 上评测；在 ALFWorld 比 GRPO 提升 >12%，WebShop 提升 >9%，且不增加 GPU memory overhead、rollout 或明显时间成本。

**解释 [本项目判断]**: 这是 `credit-assignment` track 的优先卡。它直接改变 optimizer/objective 中 advantage estimation 的粒度，而不是只换环境或 reward。
