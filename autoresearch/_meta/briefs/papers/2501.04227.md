# Brief: Agent Laboratory — Using LLM Agents as Research Assistants

- authors: Samuel Schmidgall (JHU), Yusheng Su, Ze Wang, Ximeng Sun, Jialian Wu, Xiaodong Yu, Jiang Liu (AMD), Michael Moor (ETH), Zicheng Liu, Emad Barsoum (AMD)
- arxiv: 2501.04227v2, 2025-06
- **AMD tech report**（大厂支持，可信度高于典型 arxiv）
- code: AgentLaboratory.github.io 开源

## 核心定位

**人的 idea + 机器执行**：与 AI Scientist v1/v2 从 idea 到 paper 全自动不同，Agent Lab 接收 human research idea + notes，输出 code repo + report；每 stage 可插 human feedback（copilot mode）。设计哲学：complement 而非 replace human ideation。

## Pipeline（3 phase）§3

**Phase 1: Literature Review** §3.1
- PhD agent 用 arXiv API + 3 action：`summary`（top-20 abstract）、`full text`（specific paper 全文）、`add paper`（加入 curated review）
- 迭代直到达到 N_max relevant text

**Phase 2: Experimentation** §3.2
- Plan Formulation：PhD + Postdoc 对话 → 用 `plan` 命令固化实验计划（哪些 model / dataset / high-level step）
- Data Preparation：ML Engineer + SW Engineer 迭代写数据 code，`Python command` 执行 + compiler 验证
- Running Experiments：**mle-solver** 模块：
  - A. Command Execution：EDIT / REPLACE 两种 op 修改代码
  - B. Code Execution：编译 + 自动 repair
  - C. Program Scoring：LLM 打分 (0-1) 判"与目标对齐度"（类比 AIDE 的 solution space search，但打分**代码 + outcome** 而非单 accuracy）
  - D. Self-Reflection：succeed 反思如何提分，fail 反思如何修 bug
  - E. Performance Stabilization：top program sampling + batch-parallelization（N modification 并行取最好，替换 top pool 最差）

**Phase 3: Report Writing** §3
- **paper-solver** 模块生成 report

## 关键实验

**Setup 1：Autonomous mode**（无 human）§4.1
- 5 research question × 3 LLM backend (gpt-4o / o1-mini / o1-preview) = 15 papers
- 10 PhD student volunteer × 3 paper each，1-5 分打 Experimental / Report / Usefulness

**Setup 2：NeurIPS-style eval** §4.1.1
- 同 15 篇，人类按 quality/significance/clarity/soundness/presentation/contribution 打 1-4
- **Auto-reviewer vs Human reviewer 落差**：自动 6.1/10，人评 3.8/10，**overall diff -2.3 分**（Figure 6）

**Setup 3：Co-pilot mode** §4.2
- 用户自选 topic + 每 stage 提供 feedback；外部 evaluator 打分
- Co-pilot vs autonomous（外部评分）：quality +0.75, soundness +0.48, overall +0.58

**Setup 4：MLE-Bench** §5
- 自建 mle-solver 与 MLAB、OpenHands、AIDE 对比，claim 更多 gold/silver medal（**具体数据 需读完整 §5**）

## 关键 findings（作者结论）

1. o1-preview 综合最好（usefulness 4.4/5, 4.0/10 overall）
2. o1-mini experimental quality 最高（3.2/5）——推理弱但 code 能力强
3. gpt-4o 全面落后
4. **Human involvement 每 stage feedback 显著提升质量**（copilot mode 全指标提升）
5. **Auto reviewer 系统性高估**：6.1/10 vs 人评 3.8/10——直接实证 auto reviewer 与 human 脱节
6. Topic 敏感：image noise 主题 gpt-4o 得 1.5/5 vs o1-mini 4.0/5（2.5 分差）

## 与本项目关系

- **canonical-anchor 例外保留**：与 AI Scientist 并列的 end-to-end pipeline，**human-in-the-loop 版本**——比 v1/v2 明确 acknowledge human 的必要性
- 直接实证 `reviewer-model-hacking`：**auto reviewer 6.1 vs 人评 3.8 差 2.3 分**——比 SoundnessBench 更直接的 automated reviewer 失效证据
- 直接实证 `human-in-the-loop-hidden` 是**必需而非缺陷**：作者立场明说 LLM 应 complement 人 → 与 AI Scientist "fully autonomous" claim 形成对立命题
- mle-solver 与 AIDE 直接对比：说明 tree search + code solver 的方法学演化路径（v1 → AIDE → mle-solver → AI Scientist v2）
