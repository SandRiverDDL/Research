# Brief: SoundnessBench — Can Your AI Scientist Really Tell Good Research Ideas from Bad Ones?

- authors: Sy-Tuyen Ho, Minghui Liu, Huy Nghiem, Furong Huang (UMD)
- arxiv: 2605.30329v1, 2026-05
- venue: arxiv（**Furong Huang 组**，可信度较高）
- project page + HF dataset 开源

## 核心问题

autoresearch agent 都在做 execution（MLE-Bench / PaperBench / InnovatorBench 全测跑通），**没人测 pre-execution 判断能力**——LLM 能不能在花几十小时训练前把烂 idea 挡掉。

## 定位（Table 1 自摆）

vs prior：
- MLE / PaperBench / InnovatorBench / AIRS：execution stage、outcome 判定 → 不测 pre-exec soundness
- Si2024（人类专家 ideation eval）、RINoBench：pre-exec 但测的是 **novelty**
- HindSight / Tong2026：post-hoc、future impact
- **SoundnessBench = pre-exec + methodological soundness + proposal-only input + expert label** 独有位置

## 数据构建（5-step pipeline）

- Step1 采集：ICLR 2022-2026，35,209 submissions + 137,940 reviews；filter 高 reviewer agreement（confidence≥3, soundness score std<0.15），去 desk reject
- Step2 label：reviewer **soundness sub-score**（不是 accept/reject/overall）：mean≥3 = high soundness (641)，≤2 = low (458)，中间去掉。**expert-derived proxy for recoverable proposal-stage validity**
- Step3 proposal extraction：Gemini 2.5 Pro 抠 abstract + related work + risk + hypothesis + experiment design，**去掉 results 和 acceptance cue**，near-verbatim（防 paraphrase drift）；format follow AI Scientist v2
- Step4 verification audit：atomic-claim 分解 + BM25 retrieval + LLM verify，τ=0.7 保留 66.93%（source fidelity 硬门槛）
- Step5 final：1099 proposal，16 subfield

## 关键实验

12 frontier model（GPT-4o/5.4/5.4-mini, Claude-Opus/Sonnet 4.6, Gemini 2.5-Pro/3-Flash/3.1-Pro, Qwen3.5, Llama-3.3-70B, Kimi-Linear）× 2 prompt（standard / aggressive）

**Standard prompt**（Table 2）：
- Mean **Low Recall 26.0% ⇒ FPR 74%**，Mean High Recall 91.8%
- 9/12 model 把 >70% low-soundness 判成 high
- 最优 GPT-5.4：Low R 64.6% / High R 74.6% / Macro F1 69.7
- 最差 LLaMA-3.3-70B：Low R 2.0%（几乎全判 sound）
- **optimism bias 广泛**

**Aggressive prompt**（默认拒绝）：
- Mean Low R 80.1%，但 **High R 崩到 36.1%**
- GPT-5.4 / GPT-5.4-mini：Low R 100% / High R 0-0.2%（全拒）
- Macro F1 反而降到 49.3（比 standard 54.9 差）
- 结论：**calibration 不稳，只是把 FP 换成 FN，没有真判断力**

**Scale 分析（Qwen3.5 2B→122B）**：
- Standard prompt：High R 71.8%→92.8%（好），**Low R 31.0%→19.2%（更 permissive）**——scale up 更乐观，不是更 rigorous
- Aggressive prompt：scale up 无系统改善

## Robustness controls（防 label 噪声/leakage/contamination）

- ICLR 2026-only split（cutoff 后）：optimism bias 仍稳
- Identifier removal / surface feature / adversarial injection：不改变主结论
- Human audit：low leakage、broad agreement with labels

## Limitations（作者自认）

- Reviewer soundness 是 proxy，不是绝对 truth
- Proposal-only 缺 results，模型看到的比 reviewer 少
- Prompt 空间未穷尽（只测 2 个）
- 域限 ML/CS

## 与本项目关系

- 补 evaluation 层 **soundness 档**（此前只有 novelty/impact/execution 层）
- Anchor：**LLM 作为 first-gate reviewer 不可靠**——本项目 verifier-blind-spot / reviewer-model-hacking 的直接实证证据（不再是 speculation）
- 与 HindSight 互补：SoundnessBench 测 idea 内部逻辑，HindSight 测 idea 未来匹配
- 对 AI Scientist v1/v2 / Agent Laboratory 的 auto-reviewer 是**间接证否**：这些系统 verifier 用同类 LLM，本 bench 证明这类 verifier 有 74% FPR
