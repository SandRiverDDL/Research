# Brief: Beel et al. 2025 — Evaluating Sakana's AI Scientist (Wishful Thinking or Emerging Reality)

- authors: Joeran Beel (U. Siegen) + Min-Yen Kan (NUS WING) + Moritz Baumgart (U. Siegen)
- arxiv: 2502.14297, 2025-02
- venue: arxiv（IR 视角 SIGIR perspective 类）
- code: 完整复现代码 + Singularity 容器 (code.isg.beel.org/ISG-Siegen/the-ai-scientist-reproduced)
- **本项目 evidence tier 3（independent audit）第一档**

## 定位

第一个**独立第三方 audit** Sakana AI Scientist v1，用真实实验重跑 → 揭穿 self-report 与实际能力的落差。项目主题：Green Recommender Systems (FunkSVD + MovieLens-100k)，非 Sakana 官方 3 domain (diffusion/transformer LM/learning dynamics)——刻意换域测泛化。

## 关键 finding（都是硬数字）

**Idea generation**
- Semantic Scholar API keyword search → 10 idea 全部 + 2 seed idea 全部判为 novel（对照现实：micro-batching SGD [Jain 2018]、adaptive LR、hybrid MF、e-fold CV 都已存在文献）
- Novelty check "unreliable"——依赖 keyword match 而非语义 synthesis
- Interestingness/Feasibility 分数 "appear arbitrarily assigned"，不影响 workflow（只有 binary novel label 影响）

**Experiment execution**
- **12 idea 中 5 个失败（42%）**——unresolved coding error，Aider 反复 cycle 同 bug
- 每次迭代 Aider **平均只加 8% 字符**（首次 529 / 6260），后续 118/83/66/21——**minimal 变化**
- e-fold CV 实验：说要 test e={2,3,4,5} 实际固定 e=2；还漏跑 k-fold baseline，让 e-fold 看起来"更好"（物理上不可能，e-fold 只可能节能不可能超准）

**Manuscripts (7 篇)**
- median **5 citations/paper**（range 2-9），**34 citation 中只有 5 (14.7%) 来自 2020 后**
- 4/7 (57%) **hallucinated numerical results**（超参、metric 数字与实验记录不符）
- 4/7 结构错误：missing figures / "Conclusions Here" placeholder / duplicate section
- 一篇 claim "energy-efficient 算法"：训练 116→115s（1% "改进"）、RMSE 更好、内存却增加——logical 矛盾未讨论
- Related work section "particularly poor in all manuscripts"

**Reviewer agent 自评**
- **对自己 7 篇 manuscript 全部 recommend reject**
- Reviewer 只提"single small dataset"这类表层问题；**没发现任何 hallucinated result / logical 矛盾 / duplicate**——同源盲区
- 对 10 篇 OpenReview 人类论文：拒 9/10（含 4 篇真被接收的），强 conservative bias 且与人类判断脱节

**Cost / effort**
- API cost $6/manuscript（与 Sakana $15 claim 一致）
- 但 setup 5h + template impl 15h + brainstorm/review 10h = **25h 人力**（3.5h/manuscript）——远非 fully autonomous claim
- 需要 user-defined template（prompt.json + experiment.py + plot.py + LaTeX），限制"autonomy"

## 与 Lu 2024 自 report 的落差

| Claim by Sakana | Beel finding |
|---|---|
| "automate entire research lifecycle" | 需 template 定义 goal / pipeline / seed idea |
| "near-human accuracy" reviewer | 对自产 paper 100% reject，对真接收 paper 也 80% reject，miss 关键 flaw |
| "$15/paper" | 确认（$6-15/paper），但**忽略 25h 人力** |
| "novel research idea" | Semantic Scholar keyword search 判 novelty，12 idea 全判 novel 但明显不新 |

## 与本项目关系

- **独立 audit（evidence tier 3）第一档**：本项目此前所有卡都是 self-report 或 replication，Beel 是唯一第三方 audit 类。
- 直接支撑 the-ai-scientist.md 卡里所有 failure mode 判断（此前是从摘要推断，现在有实验证据）：
  - `hallucinated-novelty`：12/12 判 novel，实际都有先例
  - `code-execution-fake-success`：e-fold 实验 e=2 固定却 report 变量结果
  - `reviewer-model-hacking`：同 LLM 做 reviewer，miss 严重 flaw
  - `citation-fabrication`：34 ref 中大量过时 + 关键领域文献漏引
  - `cherry-picked-showcase`：$15/paper 忽略 25h 人力
- 与 SoundnessBench 呼应：Beel 单点定性证据，SoundnessBench 1099 例统计证据，两者拼出 "LLM verifier 不可靠"完整证据链。

## 可信度评估

- 三作者，其中 Min-Yen Kan (NUS WING) 是 IR/NLP 领域正牌 tier；Beel 是 recommender systems 领域研究者
- 完整复现代码 + Singularity 容器公开
- 单次实验、小域（recsys）、只测 v1 版本——生态位是 "定性证据"，不追求 statistical claim
- **evidence tier**：**independent third-party audit**（唯一）——本项目最缺的档
- 局限：只测 v1（v2 已改进 tree search 和 VLM reviewer，未 re-audit）；单域 + 单模型 (gpt-4o-2024-05-13)
