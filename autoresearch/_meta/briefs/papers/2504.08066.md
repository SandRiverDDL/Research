- authors: Yutaro Yamada, Robert Tjarko Lange, Cong Lu, Shengran Hu, Chris Lu, Jakob Foerster, Jeff Clune, David Ha (SakanaAI + UBC + Vector + Oxford FLAIR)
- arxiv: 2504.08066, 2025-04
- venue: arxiv（Sakana 官方 tech report）
- code: GitHub SakanaAI/AI-Scientist-v2 开源

## v1 → v2 关键改动

| 维度 | v1 | v2 |
|---|---|---|
| Codebase 来源 | Topic-specific human template | Domain-general 自主生成 |
| Experiment 结构 | Linear | Tree-based (parallel) |
| Reviewer | LLM-only | LLM + VLM feedback on figures |
| Human eval | 未提交 peer review | ICLR workshop submission |
| Manuscript writing | Aider incremental | Single-pass + o1 reflection |

## 核心机制：Agentic Tree Search (§3)

**4 个 stage**（Experiment Progress Manager Agent 协调）：
1. **Preliminary Investigation**：最小 prototype，跑通即结束
2. **Hyperparameter Tuning**：训练收敛 + 至少 2 数据集 successful → 结束
3. **Research Agenda Execution**：core agenda，budget 耗尽 → 结束（如果比预算快，agent 增复杂度）
4. **Ablation Studies**：ablation，budget 耗尽 → 结束

**Tree Search（§3.2.2）**：
- 每 node = 一次代码 + 执行；分类 buggy / non-buggy
- 每 iteration 平行 expand 多 node；一定概率选 buggy 做 debug，否则 best-first search
- **LLM evaluator** 挑最佳 node（基于 metric + training dynamics + plot 质量）
- 特殊 node 类型：hyperparameter / ablation / replication (多 seed) / aggregation (整合 stat)
- 每 stage 结束 launch **多个 replication** 算 mean±std——比 v1 单次 run 严一档

**VLM 集成（§3.4）**：
- Experiment 阶段：检查生成图是否 accurate 传达结果
- Writing 阶段：figure 与 caption 对齐、legend/label 清晰度、检 main text/appendix 重复图

**Idea generation（§3.1）**：
- 从 topic 层面开始（不是从既有 code base）
- Semantic Scholar in-the-loop 检 novelty，非 post-hoc

## 关键 evaluation：ICLR 2025 ICBINB workshop

**Setup（§4.1）**：
- 3 manuscript 提交到 workshop（43 篇总投稿）
- Reviewer 提前知情"部分投稿可能 AI-generated"但不知具体哪几篇
- 全 accept 后 **post-review withdrawal**（避免正式记录）

**Outcome**：
- 1/3 获 6/6/7 = **平均 6.33**（top 45%，够 workshop accept 门槛）
- 2/3 分数低不 accept
- Accepted paper 主题：LSTM 上的 temporal consistency regularizer 用于 compositional generalization——**negative result paper**（结果显示 regularizer 没显著改善甚至有害）
- Reviewer 觉得报告 negative result 很好，但批评"insufficient justification for why the chosen regularization would enhance compositionality"

**作者内部审计（§4）自认限制**：
- Citation hallucination inaccuracies
- 缺 methodological rigor 和 in-depth analysis，"none met top-tier main-track conference quality"
- 只到 workshop 水平

## Human intervention（§4.2）——重要！

作者明说的 human step（"meta-selection"）：
1. 提供 workshop theme prompt
2. 系统生成约 40 idea，**人挑 3 个**（based on alignment + potential interest）
3. 每 idea 用多个 random seed 各跑一次完整 pipeline
4. **人从每 idea 的多个 seed manuscript 中挑最好那份**提交

作者定性："high-level experimental setup and process management（meta-selection）"，坚称单次 run 内**代码/结果/图/文本无人编辑**。但从 pipeline 端到端角度：**结果分布经过至少两次人工挑选**，report 的是 top-of-tail 而非平均表现。

## 与本项目关系

- **canonical-anchor（例外保留）**：end-to-end 里程碑，"first AI-generated peer-review-accepted workshop paper"是命名事件
- 对比 v1 直接改进：template 依赖去掉、tree search 替代 linear、multi-seed replication 加入
- 但**关键 failure mode 仍在**：citation hallucination 自认；reviewer selection bias（3 篇挑 1 accept 用的 human meta-select）；ICBINB 特殊（negative-result-friendly workshop）
- 与 Beel 2025 直接呼应：Beel audit 的是 v1，v2 是否修复 42% code fail、8%/iter change、fake success 等**未被独立 audit**
- 与 SoundnessBench：v2 的 LLM evaluator（node 打分）本质是 first-gate，SoundnessBench 说这种 first-gate 有 74% FPR

## 可信度评估

- Sakana 官方 tech report，Yamada + Lange + Lu + Clune + Ha 团队
- 开源代码
- **evidence tier：self-report**（ICBINB 是外部 peer review，比 v1 内部 automated reviewer 高一档；但 human meta-selection 让 report 的成绩不能视为 raw pipeline output）
- 未做与 v1 的定量对比（fail rate、code change per iter、citation freshness 等 Beel 报的数字），未 replication

## 值得追问的 gap

1. Tree search 平均要多少 node 才出一份 workshop-worthy manuscript？作者没 report acceptance rate over pipeline runs
2. Multi-seed selection bias 大小：如果只跑单 seed 单 idea，acceptance 概率会降到多少？
3. VLM feedback loop 对哪类 figure 错误最有效？未 ablation
4. o1 reflection stage 对 hallucination 抑制作用未量化
5. ICBINB negative-result workshop 特殊：普通 workshop / main track 上 v2 表现未测
