# Autoresearch Open Questions

## Scope

- 是否把 autonomous experimentation（Chemcrow / Coscientist / lab robotics）作为一等公民，还是只在其 pipeline mechanism 可迁移时收录？
- AI-driven peer review（reviewer model 本身）算 autoresearch 子系统还是独立支线？倾向前者但需要在写第一批 critique 卡后确认。
- 是否把 research idea generation（不涉及执行的 pure ideation 系统）单独列 sub-lens？

## Card Schema

- `critique-audit` 卡是否需要额外的 required frontmatter（如被 audit 的目标 system）？先不加，等真写卡时观察。
- 三档证据（self-report / third-party / audit）是否要成为独立字段还是保留为 mechanism 段落内标注？先做内文标注，看是否会频繁跨卡比较。

## Recall

- 除了 arXiv / OpenReview，是否需要主动追踪特定 workshop（AutoML、AI4Science、AgentBench）？
- 中文 autoresearch 系工作（清华 / 智源 / 中科院）如何纳入？先按同样标准处理，不因 venue 降级。

## Synthesis

- 第一张 comparison table 应该按什么轴组织：pipeline stage / verifier type / evaluation protocol / failure profile？倾向从 pipeline stage 开始，但等 3-5 张卡后再定。
- 是否输出一份 "autoresearch reproducibility scorecard" 作为 lens 产物？属于 nice-to-have，写完首批卡后评估。
