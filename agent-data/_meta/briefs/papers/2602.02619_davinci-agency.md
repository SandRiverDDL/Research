# Brief: daVinci-Agency

Source: arXiv HTML / abstract page, arXiv:2602.02619, submitted 2026-02-03.

## Bounded Source Notes

- Position: long-horizon agent training data built from real-world PR evolution, not isolated single-issue tasks.
- Data object: chain-of-PR trajectories; a PR chain is an ordered sequence of semantically linked PRs where later PRs iterate on, fix, or extend earlier ones.
- Construction: curated nine representative GitHub repositories using scale/maturity, community interactivity, and linguistic diversity criteria.
- Trajectory scale: by chaining up to five PRs, constructs trajectories averaging 85k tokens and 116 tool calls.
- Training signal: rejection sampling / evaluation against evolving ground-truth states yields high-quality data for supervised fine-tuning.
- Results: fine-tuning GLM-4.6 on 239 samples reports 47% relative gain on Toolathlon; paper also reports Qwen3-30B-A3B fine-tuning results.

## Project Use

Treat as a core seed for long-horizon real-log mining: if internal PR/task histories exist, preserve dependency chains and evolving repository states instead of flattening them into independent issue demos.
