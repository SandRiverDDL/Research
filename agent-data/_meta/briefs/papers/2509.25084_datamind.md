# Brief: DataMind / Scaling Generalist Data-Analytic Agents

Source: arXiv abstract page / API, arXiv:2509.25084v3, submitted 2025-09-29, revised 2026-03-12. Comment: ICLR 2026.

## Bounded Source Notes

- Motivation: open-source models struggle with diverse-format, large-scale files and long-horizon, multi-step reasoning required by real-world analytics.
- Recipe: scalable data synthesis and agent training for generalist data-analytic agents.
- Data method: fine-grained task taxonomy; recursive easy-to-hard task composition; knowledge-augmented trajectory sampling; model-based and rule-based filtering.
- Training: dynamically adjustable objective combining SFT and RL losses; memory-frugal stable code-based multi-turn rollout.
- Dataset/model: DataMind-12K trajectory set; DataMind-14B and DataMind-7B.
- Claimed result: DataMind-14B average score 71.16% on multiple data-analysis benchmarks, outperforming DeepSeek-V3.1 and GPT-5; DataMind-7B best open-source at 68.10%.

## Project Use

Treat as high-priority seed for the user's weakest benchmark slice: data processing and analysis.
