# Brief: Bilevel Data Curation

Source: arXiv abstract page, arXiv:2511.21056v2, submitted 2025-11-26, revised 2026-06-22.

## Bounded Source Notes

- Current title: Bilevel Data Curation for LLM Fine-tuning: Offline Selection and Online Self-Refining Generation.
- Position: unifies offline data selection with online self-refining generation for SFT data quality.
- Offline part: bilevel data selection chooses question-response pairs from an SFT dataset to maximize validation performance.
- Limitation addressed: offline selection may discard harmful responses together with useful questions, reducing question diversity.
- Online part: selected questions can have responses regenerated/refined; bilevel multi-objective optimization provides response-level weighting adapted to regenerated responses.
- Boundary: not agent-specific; relevant to target-failure data flywheels and online response repair.

## Project Use

Treat as supporting method for failure repair loops: benchmark bad cases can define validation slices, offline filtering can keep high-value questions, and online regeneration can repair weak agent responses without losing task diversity.
