# Brief: Agent Data Protocol

Source: arXiv abstract page / API, arXiv:2510.24702v2, submitted 2025-10-28, revised 2026-03-04.

## Bounded Source Notes

- Motivation: large-scale agent SFT is rare partly because agent training data is fragmented across heterogeneous formats, tools, and interfaces.
- Method: ADP is a lightweight representation language acting as an interlingua between diverse agent datasets and unified downstream training pipelines.
- Coverage: API/tool use, browsing, coding, software engineering, and general agentic workflows.
- Experiment: authors unify 13 existing agent training datasets into ADP and convert standardized data into training-ready formats for multiple agent frameworks.
- Claimed effect: average performance gain of about 20% over corresponding base models and SOTA or near-SOTA on coding, browsing, tool use, and research benchmarks without domain-specific tuning.
- Release claim: code and data are publicly released.

## Project Use

Treat as a protocol / data-format seed rather than a single data-generation method.
