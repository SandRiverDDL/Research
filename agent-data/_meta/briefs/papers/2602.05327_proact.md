# Brief: ProAct

Source: arXiv HTML / abstract page, arXiv:2602.05327v1, submitted 2026-02-05.

## Bounded Source Notes

- Position: interactive long-horizon agents fail because internal future-state simulation accumulates errors.
- GLAD: Grounded LookAhead Distillation fine-tunes the agent on trajectories derived from environment-based search, compressing search trees into concise causal reasoning chains.
- MC-Critic: auxiliary value estimator for policy-gradient methods such as PPO / GRPO, using lightweight environment rollouts to calibrate value estimates.
- Testbeds: 2048 and Sokoban provide objective long-horizon interactive environments with stochastic and deterministic dynamics.
- Result claim: a 4B model trained with the framework outperforms open-source baselines and approaches closed-source systems, with generalization to unseen environment configurations.
- Boundary: GLAD is directly relevant to SFT data; MC-Critic is agentic RL and should be read from data-consumer rather than optimizer lens here.

## Project Use

Treat as a core seed for search-to-SFT distillation: use environment search / rollout to create concise foresight supervision for failure-switching and long-horizon planning, but keep MC-Critic in the RL-overlap bucket.
