# Brief: FastMix

Source: arXiv HTML / abstract page, arXiv:2606.14971v1, submitted 2026-06-12.

## Bounded Source Notes

- Position: data mixture optimization for pre-training and post-training with only a single proxy model.
- Core formulation: mixture selection is framed as a bilevel optimization problem; optimizing mixture ratios is equivalent to assigning per-source loss weights under uniform source sampling.
- Algorithm: alternates between updating model parameters on data sampled under current mixture ratios and updating mixture ratios from validation feedback.
- Efficiency claim: figure summary reports large time-cost reductions versus proxy-model search methods such as CLIMB and RegMix.
- Boundary: not agent-specific; useful only as a supporting method for agent SFT mixture / ablation.

## Project Use

Treat as supporting data-flywheel method: after defining agent data buckets and validation slices, use the paper as a seed for replacing manual ratio sweeps with validation-driven mixture updates.
