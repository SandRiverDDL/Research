# Brief: Data Mixing Optimization for SFT

Source: arXiv HTML / abstract page, arXiv:2508.11953v1, submitted 2025-08-16.

## Bounded Source Notes

- Position: data mixing optimization specifically for supervised fine-tuning.
- Problem: pre-training mixture methods may not transfer to SFT because proxy-model weights may not scale and loss parameterizations can ignore domain interactions.
- Method: parameterizes validation loss using effective transferred data and fine-tuning scaling laws, then derives optimal domain weights under a fixed data budget.
- Domains: controlled experiments include instruction following, math, and code; method also reweights popular SFT collections.
- Reported result: optimized weights perform close to grid-search optimum, with average per-domain loss only 0.66% higher than best domain loss from grid search.
- Boundary: predates project’s 2025Q4 preference but is a directly relevant SFT mixture anchor.

## Project Use

Treat as supporting SFT mixture anchor: it gives a principled baseline for converting benchmark validation slices into domain weights before running expensive full agent SFT ablations.
