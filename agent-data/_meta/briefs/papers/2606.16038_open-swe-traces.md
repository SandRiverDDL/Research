# Brief: Open-SWE-Traces

Source: arXiv API, arXiv:2606.16038v1, submitted 2026-06-14.

## Bounded Source Notes

- Motivation: autonomous software engineering is bottlenecked by lack of diverse, large-scale trajectory data.
- Dataset: 207,489 agentic trajectories across nine programming languages: Python, Go, TS, JS, Rust, Java, PHP, C, C++.
- Source: 20,000 real-world PRs via OpenHands and SWE-agent harnesses.
- Synthesis: hybrid-reasoning synthesis; Minimax-M2.5 generates explicit thinking trajectories, Qwen3.5-122B provides non-thinking traces.
- Filtering: permissive licenses from SWE-rebench-V2.
- Validation: fine-tunes Qwen3-30B-A3B series.
- Claimed result: best model reaches 61.7% on SWE-bench Verified, 57.1% on SWE-bench Multilingual, and 36.8% on SWE-bench Pro.

## Project Use

Treat as core seed for real-world PR trajectory mining and dual-mode distillation.
