# Brief: PC Agent-E / Efficient Agent Training for Computer Use

Source: arXiv abstract page / API, arXiv:2505.13909v2, submitted 2025-05-20, revised 2026-03-03.

## Bounded Source Notes

- Motivation: high-quality trajectory data is a bottleneck for human-like computer-use agents.
- Seed data: 312 human-annotated computer-use trajectories.
- Augmentation: synthesizes diverse alternative action decisions using Claude 3.7 Sonnet.
- Claimed result: PC Agent-E achieves 141% relative improvement, and surpasses Claude 3.7 Sonnet by 10% relative on WindowsAgentArena-V2.
- Release claim: code, data, and models are available at https://github.com/GAIR-NLP/PC-Agent-E.

## Project Use

Treat as canonical anchor for small human seed + teacher action synthesis in GUI/computer-use SFT.
