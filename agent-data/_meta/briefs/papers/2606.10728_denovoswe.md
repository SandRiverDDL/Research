# Brief: DeNovoSWE

Source: arXiv abstract page / API, arXiv:2606.10728v2, submitted 2026-06-09, revised 2026-06-16.

## Bounded Source Notes

- Motivation: code agents are moving from localized bug fixing toward whole-repository generation, but verifiable whole-repo training data is scarce.
- Dataset: 4,818 high-quality whole-repository generation instances from documentation.
- Construction: automatic sandboxed agentic workflow without human annotation.
- Method philosophy: divide-and-conquer plus critic-repair.
- Selection: difficulty-aware trajectory filtering to balance data quality and diversity.
- Claimed result: fine-tuning Qwen3-30B-A3B improves BeyondSWE-Doc2Repo from 5.8% to 47.2%.

## Project Use

Treat as core seed for synthetic verifiable long-horizon SWE data and difficulty-aware trajectory filtering.
