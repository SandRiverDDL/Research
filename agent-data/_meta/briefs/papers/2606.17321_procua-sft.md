# Brief: ProCUA-SFT

Source: arXiv abstract page / API, arXiv:2606.17321v1, submitted 2026-06-15.

## Bounded Source Notes

- Motivation: computer-use agents need large, diverse trajectory data collected in full desktop environments.
- Negative-transfer claim: continuing UI-TARS 7B on AgentNet human trajectories lowers OSWorld success from 26.3% to 8-10%.
- Dataset: 3.1M step-level SFT samples distilled from 93K synthetic trajectories across 2,484 application combinations.
- Pipeline: synthesizes grounded tasks on live desktops seeded with real-world content such as SpreadsheetBench spreadsheets, Zenodo10K presentations, and OSWorld configs.
- Focus: automated task generation and verification, precondition checking, VLM / UI-TARS-style computer-use SFT.

## Project Use

Treat as core seed for synthetic GUI trajectories, step-level samples, and negative-transfer-aware data curation.
