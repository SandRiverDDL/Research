# Brief: ASTRA

Source: arXiv HTML / abstract page, arXiv:2601.21558v2, submitted 2026-01-29.

## Bounded Source Notes

- Position: automated end-to-end framework for training tool-augmented LLM agents with synthetic SFT trajectories plus verifiable multi-turn RL arenas.
- SFT data: collects and normalizes tool documents from open MCP registries, API platforms, internal specs, and public datasets into OpenAI-style tool-calling schema.
- Tool coverage: after grouping/filtering, retains 1,585 MCP servers and 19,036 tool documents across 41 domains.
- Trajectory synthesis: uses tool-call graph / transition-graph topology to synthesize task-conditioned tool chains, then samples candidate chains with dependency and task-chain coherence checks.
- Environment synthesis: converts decomposed QA traces into independent, code-executable, rule-verifiable environments for deterministic multi-turn RL.
- Boundary: data pipeline is central, but training methodology also includes online multi-turn RL with trajectory-level rewards and irrelevant-tool mixing.

## Project Use

Treat as a core seed for synthetic verifiable tool data: graph-structured tool topology can generate multi-step trajectories, while executable environments turn SFT data into pre-RL / RLVR-ready tasks.
