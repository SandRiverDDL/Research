# Brief: Dr. Post-Training

Source: arXiv abstract page, arXiv:2605.07063v1, submitted 2026-05-08.

## Bounded Source Notes

- Position: post-training data selection under scarce high-fidelity target data plus abundant imperfect general data.
- Core reframing: general data is treated as a data-induced regularizer that prevents overfitting to the target objective, not merely as a pool for selection.
- Mechanism: at each training step, construct a feasible set of update directions from general data and project the target-data update direction onto that set.
- Theory lens: standard training and existing data selection are special cases corresponding to different regularization strengths on a bias-variance spectrum.
- Scope: experiments span SFT, RLHF, and RLVR; paper emphasizes practical system optimizations for LLM-scale use.
- Boundary: not agent-specific; useful for target benchmark data vs general ability tradeoff.

## Project Use

Treat as supporting method for regression control: when adding narrow failure-targeted agent data, use the regularization lens to decide how much general / historical agent data must remain in the mix.
