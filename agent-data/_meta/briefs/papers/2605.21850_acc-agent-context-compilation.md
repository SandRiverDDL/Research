# Brief: ACC: Compiling Agent Trajectories for Long-Context Training

Source: arXiv abstract page / API, arXiv:2605.21850v2, submitted 2026-05-21, revised 2026-06-14.

## Bounded Source Notes

- Motivation: agent trajectories contain multi-turn tool calls and environment observations; evidence needed to answer the original question is scattered across distant turns.
- Claimed gap: standard agent SFT masks tool responses and trains turn-level tool selection, leaving a supervision blind spot over distant evidence.
- Method: Agent Context Compilation converts trajectories from search, software engineering, and database querying agents into long-context QA pairs combining the original question with tool responses and environment observations.
- Evaluation claim: Qwen3-30B-A3B trained with ACC reaches 68.3 on MRCR (+18.1) and 77.5 on GraphWalks (+7.6), while preserving GPQA, MMLU-Pro, AIME, and IFEval.
- Mechanism claim: ACC-trained model shows task-adaptive attention restructuring and expert specialization.

## Project Use

Treat as a core seed for `search-to-sft-distillation` and long-context observation grounding in agent SFT.
