# Harness RL Seed Sources

核查日期：2026-10-16。局部阅读与摘要核查分别标注；不表示系统覆盖或全文读完。

- [CompactionRL: Reinforcement Learning with Context Compaction for Long-Horizon Agents](https://arxiv.org/abs/2607.05378)：用户指定入口；已核查 v2 §2–3、§4.3 与 Limitations，详见 compactionrl-reading-matrix；未完整精读实验或复现。
- [LEGO-RL: Harness-Native Reinforcement Learning for Coding Agents](https://arxiv.org/abs/2608.17393)：原生 harness 下的 policy-gradient training 与 token / log-prob 对齐；仅摘要核查。
- [Harness-1: Reinforcement Learning for Search Agents with State-Externalizing Harnesses](https://arxiv.org/abs/2606.02373)：状态外置 harness 下训练 search policy；仅摘要核查。
- [Co-Harness: Co-Evolving Harnesses and Model Weights for LLM Agents](https://arxiv.org/abs/2607.22688)：harness / weights 协同优化的邻近对照；摘要描述微调，不直接当作 RL 算法。
- [OpenForgeRL: Train Harness-native Agents in Any Environment](https://arxiv.org/abs/2607.21557)：v3 §5.2–5.3 局部核查；单 / 多 harness SFT+RL 对照与 RL 行为分析，未完整精读。
- [HarnessBandit: Joint Learnability-Transferability Scheduling for Multi-Harness Agentic Reinforcement Learning](https://arxiv.org/abs/2609.13739)：共享 policy 的六 harness RL 调度；只核查原始摘要。
