# 因果微型探针预测哪些教师—学生—数据三元组能够蒸馏

**方法名称：** Teacher-Causal Response Probe (TCR-Probe)

## 研究动机
在 on-policy distillation (OPD) 中，有用的教师并不只是最强的模型。教师是否有帮助，取决于具体的教师、学生和数据三元组。学生必须访问到教师掌握且与结果相关的前缀，收到以当前能力仍可学习的 target，并把这个局部信号转化为最终任务提升。已有工作分别研究了冻结教师在学生状态上是否可学习、推理模式重叠与可恢复的教师知识、位置相关的可教性，以及监督 fidelity 的衰减。

尚未解决的问题是：能否在完整 OPD run 之前计算一个分数，并且不经重新校准就用于未见过的教师家族、学生能力和数据分布。原始早期提升无法回答这个问题，因为它把教师特异的迁移与学生对 probe buffer 的一般适应混在了一起。TCR-Probe 比较两个其余条件相同的短训练分支：一个使用候选教师的 target，另一个使用冻结学生自身的 target。它用 verifier 测得的教师 headroom 去归一化教师分支的额外响应。核心问题是：可用教师优势中真正转化为学生提升的比例，是否足够稳定，能够为三元组排序。

现在进行这种测量是及时的，因为 2026 年的研究已经提供了所需部件：学生可达的教师知识、局部可教性的崩塌、基于 verifier 的 handoff 和 fidelity 测量，以及低 Kullback–Leibler (KL) agreement 在退化前缀上可能误导的警告。同时，开放权重的 Qwen3 和 DeepSeek-R1-Distill 模型、公开的 DAPO-Math-17K 和 MATH 数据，以及 exact-answer verifier，使得无需付费 API 也可复现匹配的微训练分支。新近可行的不是又一个事后相关 proxy，而是受控的 TEACH-versus-SELF intervention：其分数保持不变，并在留出的教师家族和数据变化下接受测试。

先前工作没有完成这一步。openreview:TteFp6TLUA 考察了当能力不同时，较强的冻结教师在学生访问的状态上是否仍可学习，但没有构造匹配的 TEACH-versus-SELF 响应，也没有检验它是否能在未见三元组间为完整 run 的增益排序；它缺少一个能将教师特异迁移与一般短期适应分离的对照。arxiv:2604.13016 在受控模型家族内测量了推理模式重叠、教师新增知识和 gap recovery，但没有形成未经重新拟合、可在教师家族、能力比例和数据分布留出条件下验证的前瞻分数；它缺少一个基于 intervention 的量，能用同一学生状态 buffer 上的教师 headroom 归一化实际学生响应。arxiv:2605.13643 用学生可达的教师 margin 判断推理轨迹中监督应在何处减弱，但没有在训练前测量整个三元组的可蒸馏性，也没有通过匹配的微训练分支比较候选教师；它的测量用于单次 run 内的位置控制，而非可迁移的三元组级选择。arxiv:2605.30833 用教师 confidence 和 prefix-handoff completion 诊断监督 fidelity 衰减，并用 lookahead reward 引导训练，但没有分离候选教师相对冻结自身对照带来的额外学习，也没有针对跨三元组最终增益验证该量；其信号描述 target 质量与局部纠正机会，而非学生使用该机会后的因果响应。

如果该响应分数得到验证，研究者可在投入完整 OPD 前排除没有前景的教师—学生—数据三元组，并将教师选择变成可审计的决策，而不再依赖强度启发式。它会把局部可教性的发现连接到更强的经验结论：在已说明的 transport 条件下，经过归一化的教师特异微响应能够预测哪些三元组会把局部 headroom 转化为最终 exact-answer 提升。如果失败，则说明可蒸馏性过度依赖训练路径，固定的小预算替代指标无效，后续工作应转向训练过程中的自适应诊断。

## 方法
### background
*背景：冻结共享的学生状态，并建立 verifier 测得的可用教师 headroom。*

1. 冻结完全相同的初始学生检查点(checkpoint) $\theta 0$，并同时锁定分词器、提示模板、生成设置和随机种子。为选定的公开任务数据 Dc 中每个样本分配稳定标识，并为来源、模板或派生关系相同的样本分配防泄漏分组；随后按整组把样本放入轨迹池或独立评估切片 Ec，不能交叉。 【作者需决定：明确 Dc，并锁定拆分单位及缓冲区与评估集的比例，确保相关样本不会跨集合。】 用轨迹池生成学生作答过程，并为每条过程保存输入、参考答案句柄、提示词元、生成词元标识、词元概率以及前缀结束位置 p。 【作者需决定：锁定学生生成分布和前缀结束位置的选取规则，使 Bc 对应明确的早期学生状态分布。】 将这些前缀记录保存为不可变缓冲区 Bc，将完整评估样本保存为 Ec，并记录检查点、分词器、数据表的哈希值和全部随机种子，供后续分支原样复用。
   - _为什么：_ 固定状态、样本和初始化后，教师比较在形成因果对比前不会继承不同的 rollout 分布。
2. 对 Bc 中每条固定的 (x,p) 记录，重建完全相同的提示与前缀词元序列，并分别交给候选教师 Tc 和冻结学生 $\theta 0$。按照锁定的生成规则各生成一个续写，保存词元和停止原因，把最终答案转换成任务规定的标准形式，再由精确答案验证器 V 以 1 表示正确、0 表示错误。对每条记录的教师得分减学生得分等权取平均，得到 Hc，同时保留全部成对得分。还要缓存两种来源的训练目标，并保存词元位置、掩码、词表映射和归一化信息。 【作者需决定：在完整的下一词元概率、带已声明剩余概率质量的截断分布、采样目标序列三者中选择监督表示，并锁定相应的教师接口和缓存结构。】 教师缓存与冻结学生自身缓存必须使用完全相同的成功记录标识集合。

*在冻结的初始学生前缀缓冲区 Bc 上，用 verifier 衡量教师相对初始学生的可用 handoff headroom。*
$$ H_c = \frac{1}{|B_c|}\sum_{(x,p)\in B_c}\left[V\!\left(y^{T_c}_{x,p}\right)-V\!\left(y^{S_0}_{x,p}\right)\right] \tag{1} $$

   - _为什么：_ 当教师提供的与结果相关优势很少或很多时，相同的原始响应含义不同。Hc 为这种差异提供分母。

### matched_causal_response
*用匹配的 TEACH 和 SELF 分支测量教师特异的短训练响应，再按可用 headroom 归一化。*

3. 从 $\theta 0$ 制作两个完全相同的副本：候选教师分支 TEACH 和冻结学生自身分支 SELF。用同一组设置初始化各自的优化器状态，并让两个分支读取顺序相同的 Bc 记录、批次、样本权重、监督目标词元数、更新步数、学习率进度位置和随机数流。TEACH 读取 Tc 生成的缓存目标；SELF 只读取冻结 $\theta 0$ 预先生成的目标，绝不能改用训练过程中不断变化的 SELF 模型生成目标。两个分支采用同一套词元级蒸馏训练规则。 【作者需决定：锁定与监督表示相匹配的损失、词元损失的汇总方式、优化器与调度规则，以及两个分支完全相同的停止点。】 保存两个训练后检查点，并保存缓存哈希、记录顺序、词元数、设置、随机种子和损失轨迹，使目标来源成为唯一有意设置的分支差异。
   - _为什么：_ SELF 分支估计一般的短期适应，因此两个分支之间真正起作用的差异是 target 的来源。
4. 在顺序完全相同的 Ec 样本上评估 $\theta 0$、$\theta cTEACH$ 和 $\theta cSELF$，三者必须使用相同的提示格式、生成规则、答案标准化程序、精确答案验证器 V 和随机种子规则。保存每个模型在每个样本上的 0 或 1 得分，并把 M 定义为 Ec 上的平均得分。按照本步骤关联的定义，先计算两个训练分支相对 $\theta 0$ 的结果变化，再用 第2步（对 Bc 中每条固定的） 得到的 Hc 计算教师因果响应探针(Teacher-Causal Response Probe, TCR-Probe)分数 R(c)。在一条三元组记录中保存 Hc、两个结果变化、二者之差、R(c)、有效样本数以及三个检查点和 Ec 的哈希值。不得截断或替换 Hc。 【作者需决定：预先规定 Hc 为零、为负以及为正但接近零时如何标记和参与排序，包括何时判定比值不可解释，同时保留原始分子和分母。】

*两个匹配微训练分支在同一评估切片上的固定预算结果变化。*
$$ \Delta^{a}_c = M\!\left(\theta^{a}_c;E_c\right)-M\!\left(\theta_0;E_c\right),\quad a\in\{\mathrm{TEACH},\mathrm{SELF}\} \tag{2} $$


*Teacher-Causal Response：每单位已验证教师 headroom 所产生的教师特异性微训练增益。*
$$ R(c)=\frac{\Delta^{\mathrm{TEACH}}_c-\Delta^{\mathrm{SELF}}_c}{H_c} \tag{3} $$

   - _为什么：_ 分子去除了通用早期增益；分母考察可用教师优势中有多少转化为学生提升。报告低 Hc 能保留该量的适用边界。

### transport_and_placebo_test
*检验不变分数是否能为留出的三元组排序，以及该价值是否依赖教师—前缀对齐。*

5. 建立一张固定的三元组表，包含三元组标识、教师家族标签、数据分组标签、R(c)、Hc、冻结学生的精确答案得分、完整在线策略蒸馏(On-Policy Distillation, OPD)后的精确答案得分，以及完整训练增益 $G_{OPD}(c)$。每次完整 OPD 都必须从该三元组的 $\theta 0$ 开始，并遵循同一套固定 5M 词元流程；排序前冻结整张表。 【作者需决定：公布教师家族和数据分组归属，明确每个教师家族折是在被留出的家族上统计，还是按关联公式在 $C_-f$ 上统计，并锁定各折结果的合并或加权规则。】 在每个固定候选集合内，对并列数值使用平均名次，再计算 R(c) 与 $G_{OPD}(c)$ 的 Spearman 等级相关。将排名前三的选择后悔值定义为：真实增益最高的三个三元组的平均完整训练增益，减去 R(c) 选出的三个三元组的平均增益；仍有并列时按三元组标识确定顺序。 【作者需决定：为重叠度、间隔、置信度、教师准确率和未经校正的早期增益分别给出精确的逐三元组输入、公式、汇总单位和并列处理规则。】 在同一批留出折上原样应用 R(c) 和全部基线，并分别报告等级相关与排名前三的选择后悔值，不能用留出得分重新拟合或校准 R(c)。

*在留出一个教师家族时，未经重新拟合的 probe 分数与完整 OPD 增益之间的排序一致性。*
$$ \rho_{\mathrm{LOTF}}=\operatorname{Spearman}\!\left(\{R(c)\}_{c\in C_{-f}},\{G_{\mathrm{OPD}}(c)\}_{c\in C_{-f}}\right) \tag{4} $$

   - _为什么：_ 跨留出条件的排序，而不是在单一家族内拟合，是该响应可在训练前用于选择三元组所需的证据。
6. 对每个至少含两条 Bc 记录的三元组，按照三元组标识和样本标识的稳定哈希值排序。把循环顺序中的下一条候选教师目标分配给当前前缀。这样可保证没有前缀保留自己的目标，同时完整保留目标集合、序列长度、数值和采样权重。前缀、SELF 目标、$\theta 0$ 初始化、训练记录顺序、批次、更新步数、优化器设置、随机数流、Ec、验证器 V 和原始 Hc 都保持不变。除教师目标查询被置换外，严格按 第3步（从 $\theta 0$ 制作两个完全相同的$\dots $） 训练安慰剂 TEACH 检查点，再按 第4步（在顺序完全相同的 $Ec\dots $） 评估，并把它相对 SELF 的结果变化代入同一响应定义。将安慰剂响应写入同一张 第5步（建立一张固定的三元组表） 三元组表，计算相同的分折排序、Spearman 等级相关和排名前三的选择后悔值，并保存置换映射与哈希值。
   - _为什么：_ 如果教师 target 不再对应其前缀后选择价值仍保留，R 追踪的就是一般 learning-curve 或 target-marginal artifact，而不是教师导致的 headroom 转化。
