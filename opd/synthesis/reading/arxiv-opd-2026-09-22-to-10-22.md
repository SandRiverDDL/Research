## 3. 值得保留的跨论文结论

### 3.1 Semi、Lightning 与 ReOPD：复用对象不同

以下两篇是**窗口外背景**，不计入本月 30 篇：

- [Lightning OPD（2604.13010，§3.2）](https://arxiv.org/html/2604.13010v3#S3.SS2)：原始配方从 base 开始，用 teacher 数据 SFT 后，由学生生成固定回答并缓存 teacher 分数；训练时重新计算当前学生概率。强调 teacher consistency，但理论结论须连同假设理解。
- [ReOPD／Prefix Replay（2607.04763，§4）](https://arxiv.org/html/2607.04763v3#S4)：固定 teacher 与环境交互的历史，当前学生重新生成选中回合，teacher 重新评分；不执行新动作、不产生新环境观察。它免环境交互，仍保留当前回合生成与 teacher 推理。

**事实：**Semi 原文 §2.2 明确将其与 Lightning 的配方差异概括为省去前置 teacher-SFT，直接使用已有 instruct 学生；缓存和基于当前学生概率的更新核心接近。

**解释：**Semi 相对 Lightning 的独立算法增量有限，更适合定位为“系统经验研究＋机制解释＋简单方案”。其贡献是刻画何时冻结轨迹可以改善效果，以及低 overlap、轨迹增长与监督可靠性之间的联系。若初始化、数据、teacher 与 loss 实现没有对齐，不能把配方胜出归因于新更新算法。

**事实与边界：**Semi §5 承认初始轨迹需达到一定质量；top-k overlap 是跨配置的经验指标，尚非充分因果判据。完全固定缓存也不自动保证适合长期能力扩展。[Semi §3–5](https://arxiv.org/html/2610.11291v1#S3)

缩写注意：[REOPD：Reliability-Adaptive Reward Extrapolation（2608.11698）](https://arxiv.org/abs/2608.11698) 是另一篇奖励外推论文，不是 ReOPD／Prefix Replay。

### 3.2 模仿准确率、后续可学习性与可靠性不能混为一个分数

- **事实：**ActionOPD 的单次成功与四次全成功结果不同；JOLT 与 JOLT+ 的排序随任务和学生奖励而变。评价应保留具体 metric 与信息权限。
- **事实：**RL Starts before RL 观察到，即时准确率／有限采样 Pass@k 不足以解释后续 RL 差异；FKL／RKL 排名可能在 RL 后反转。[§5–7](https://arxiv.org/html/2609.28145v2#S5)
- **作者假说：**teacher distributional alignment 可能改善接续的概率分配，retained uncertainty 可能保留可供 RL 探索的备选；二者独立贡献未被分离。
- **测量边界：**论文的 uncertainty 主要是推理词 lexicon 匹配位置的、截断归一化候选分布的 token 熵，不是完整推理策略多样性的直接测量；各模型自身前缀上的统计也可能混入访问分布差异。[Appendix C](https://arxiv.org/html/2609.28145v2#A3)
- **解释：**高熵可能来自有用备选，也可能来自无效变化；与 teacher 更接近也不保证更正确。相关性和最终提分不足以唯一识别机制。

此前讨论的有依据验证路线，仅作为**迁移设计、未运行**保留：

| 路线 | 已发表先例 | 可检验什么／不能越过的边界 |
|---|---|---|
| 保留 argmax、置换其余概率，破坏非最高项的语义信息 | [Born Again Neural Networks，ICML 2018，§3.2／PDF p.5](https://proceedings.mlr.press/v80/furlanello18a/furlanello18a.pdf) 的 DKPP。 | 保留的是 target 熵，不保证学生最终熵相同；迁到语言生成时需避免用不合法 token 引入无关破坏。 |
| 同 checkpoint 调温，做采样随机性的救援／削弱实验 | [Beyond the 80/20 Rule，NeurIPS 2025，§2／PDF pp.4–5](https://proceedings.neurips.cc/paper_files/paper/2025/file/a797c2d2e0c1fdabf4d1ab8cd0b465c6-Paper-Conference.pdf)。 | 原先例是推理时干预；迁到 RL 需保证采样与更新概率一致。调温也改变 alignment，不能称纯 entropy 干预。 |
| 小型可枚举环境中比较采样梯度与精确梯度 | [Understanding the Impact of Entropy on Policy Optimization，ICML 2019，§3.1](https://proceedings.mlr.press/v97/ahmed19a.html)。 | 检查收益是否依赖采样覆盖／估计方差；精确梯度下仍有收益时，不能只用探索解释。小环境结论还需真实模型验证。 |

这些先例不意味着已存在一套能把 OPD 收益唯一分为 alignment 与 uncertainty 百分比的标准协议。多训练种子与区间估计的依据见 [Agarwal et al.，NeurIPS 2021](https://proceedings.neurips.cc/paper/2021/hash/f514cec81cb148559cf475e7426eed5e-Abstract.html)。

### 3.3 方法的实现成本同样影响比较意义

**研究取舍：**按当前偏好，优先考察完整 rollout 后已有数据上的 loss、选择或下一批预算改动。DIAL、具备相应概率接口时的 ResOPD、Nash 的预算调度较贴近这一条件；它们并不因此自动更强或一定更快。IPD、STI、Branch 涉及生成策略／接管／分支；R2S 涉及回放与 teacher 修复，进入候选前需要单独估计基础设施和额外计算。

## 4. Limitation、开放问题与可解性

**解释：**作者 future work 是研究入口，不等于尚无近邻的新颖方法机会，也不保证一个小改动即可提分。

| 来源与作者明确留下的问题 | 开放问题／本次推断 | 可解性与已有覆盖 |
|---|---|---|
| [Projected Distillation §6](https://arxiv.org/html/2610.27467v1#S6)：单轮为主；多轮失败可能起源于更早回合，尚未决定修哪一轮。 | 如何构造尽量接近学生、又执行一致的多轮正确目标？**猜测：**最少 token 编辑可能导致后续环境观察失效。 | 有明确诊断对象，但需处理执行成本；Graph 的信用分配、OG-OPD 的结果校准、SERO 的 oracle 接续已覆盖相邻路线。简单“定位错步＋teacher 接续”不作为 novelty。 |
| [ActionOPD §5](https://arxiv.org/html/2610.19820v1#S5)：agreement 不保证正确；matcher 会误判；固定样本数下合理决策分散可能导致少量匹配。 | 固定查询预算下，如何区分错误动作与有效但未被 teacher 采到的动作？ | 可检验监督覆盖和漏判；语义 matcher 本身已存在，执行语义也有 ASL 等先例，需明确剩余失效条件。 |
| [Vanishing Learning Signals §7](https://arxiv.org/html/2610.11247v1#S7)：理想 gradient flow／共享参数化与实际 AdamW／有噪声代理存在距离。 | 损失平台来自梯度冲突、实际更新未实现下降，还是表示限制？ | 可以先做能预测、干预并恢复学习的机制诊断；“表示变化小”本身不能证明容量上限。 |
| [R2S Limitations](https://arxiv.org/html/2610.28586v1#Sx1)：需可回放环境、大量接管和 teacher 微调，证据限于文本 agent 与有限模型家族。 | 不可回放环境中如何获得可信的长期后果评分，识别日志不支持的新状态？ | 价值高、难度高；SAPD 已免环境学习，RSD 已用 hindsight，不能把“使用日志／反思”直接当新方法。缺少反事实信息时只能有条件估计，不能保证精确恢复。 |
| [STI-OPD Appendix D](https://arxiv.org/html/2610.10878v1#A4)：需 teacher token 概率、接管整轮；未测试不可逆副作用。 | 黑盒 teacher、局部决策修正和不可逆操作下怎样干预？ | 存在真实适用边界；ActionOPD 已提供黑盒动作监督。局部替换还需保持 reasoning、动作和执行后果一致，不能只缩小文本片段。 |
| [RL Starts before RL §7](https://arxiv.org/html/2609.28145v2#S7)：alignment 与 retained uncertainty 尚未独立分离。 | 如何选择或训练真正有利于后续 RL 的初始化？ | 可做受控机制与预测研究；更换 FKL 已有正面结果，不作为新方法本身。需要预算公平与干预检查。 |
| [Nash-MOPD Limitations](https://arxiv.org/html/2610.26124v1#Sx1)：局部、可分离进步估计尚未处理跨域迁移、遗忘和延迟反馈。 | 跨任务影响如何改变预算分配？ | 存在研究空间，但 PMOPD／UP-MOPD 已处理交互与更新冲突；简单估计冲突再调度的方向较拥挤。 |
| [VC-OPD §6](https://arxiv.org/html/2610.14939v1#S6)：视觉依赖不等于推理重要性，扰动不是理想因果干预。 | 如何识别视觉不变却重要的推理控制步骤？ | 问题可测；简单叠加另一种 token 权重可能只是增量改进。 |
| [What Should a Self-Teacher See? §5](https://arxiv.org/html/2609.25623v2#S5)：依训练期信号可靠选择上下文粒度仍开放。 | 哪类特权信息能被学生内化，何时造成捷径？ | PI 效用预测与 RSD 上下文演化已有近邻；“自动选择 PI”这个宽泛提案不足以构成新颖性。 |

Semi 的可解性单独保留三点：

1. **事实：**弱初始轨迹是作者明确边界；先 SFT 是可行工程补救，但 Lightning 已这样做，不能据此提出新方法贡献。
2. **解释／信息约束：**固定缓存只包含已访问前缀的 teacher 分数。重要性加权不会凭空提供未缓存前缀的分数；要精确覆盖新状态，需要新查询或额外假设。
3. **开放问题：**作者 §5 将在线 rollout 决定的 equilibrium 留给未来研究。原文也观察到从 Semi 切回 OPD 后可能退化，所以“刷新缓存一定改善学习”不是已证前提。先确认具体失败和相近预算下的修复收益，再判断是否存在方法 gap。

### 已覆盖或应降级的宽泛提案

- **teacher 接续、结果择优和 student continuation 校准：**已有 [OG-OPD](https://arxiv.org/abs/2609.35319)、[SERO](https://arxiv.org/abs/2610.19397) 等近邻。
- **自动选择／演化特权信息：**已有 [Predicting PI Effectiveness](https://arxiv.org/abs/2610.22512)、[RSD](https://arxiv.org/abs/2610.27495)。
- **多教师梯度／更新冲突：**已有 [PMOPD](https://arxiv.org/abs/2609.34605)、[UP-MOPD](https://arxiv.org/abs/2610.08398)。
- **无偏 Top-k 与尾部方差降低：**本月 TT-OPD／ResOPD 已直接研究。
- **IPD 原型的两项限制：**其后续 §3.2–3.3 已处理推测生成和差异化监督；不能把原型的问题误记为最终方法未解决的 gap。

上述只是定向近邻核查，不是全领域 claim-level 查新，也不保证剩余切口新颖或可投。
