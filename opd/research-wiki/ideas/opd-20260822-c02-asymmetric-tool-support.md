# Effect-Space OPD for Asymmetric Tool Support

**stage:** `archived`  ·  **outcome:** `pending`

teacher 有 macro tools、student 只有 primitive tools 时在共同 effect space 蒸馏。

## Thesis
teacher action 超出 student executable support 时，raw KL 或 masking 都无法传递实现同一效果的 primitive policy。

## Key risks
Sub-goal Distillation 与 GAPD 很近；effect label/时序边界可能依赖 oracle。
