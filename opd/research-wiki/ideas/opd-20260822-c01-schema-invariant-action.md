# Schema-Invariant Action OPD

**stage:** `archived`  ·  **outcome:** `pending`

在异构工具 schema 下把 token agreement 投影到 canonical action agreement。

## Thesis
跨 schema 的 token KL 会产生 false agreement/disagreement；在 canonical action space 蒸馏可能修复。

## Key risks
TSCG、OpenAgent 与 schema augmentation 近邻过强；除非领先统一编译/augmentation，否则不启动。
