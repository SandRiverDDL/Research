## Rank 1 — C14: Two Axes of On-Policy for Agents

### 一句话 thesis

Agent OPD 把两件不同的事都叫作 on-policy：一是环境状态由 student 访问，二是进入 teacher 的文本/记忆/rationale 由 student 生成。真正的 2×2 干预可以识别它们对 exposure bias、长程错误与 transfer 的独立因果作用。

### 为什么这可能是蓝海

[DAgger for LLM agents](https://arxiv.org/abs/2605.12913) 关注 student-state occupancy；[MemOPD](https://arxiv.org/abs/2608.07068) 已指出 provenance 与 state 不是同一概念；但现有工作没有在同一可快照环境中完整 crossing：

|  | student-authored text | teacher-authored text |
|---|---|---|
| student-visited state | 标准 agent OPD 倾向的条件 | 固定状态，替换 textual provenance |
| teacher-visited state | 固定文本协议，替换 occupancy | 传统 teacher trajectory 条件 |

真正的新意不是发明术语，而是证明两条轴能独立操纵，并对应不同 failure modes。

### 最小实验

选择一个可快照、确定性较强的 agent 环境。保存同一 underlying state 的 observation、memory 与 action history，然后分别由 student/teacher 重述 textual context；反向地，在固定 text protocol 下切换 student/teacher occupancy。四格严格匹配 teacher calls、action tokens、训练 tokens 与 optimizer budget。

指标不只报最终 success，还要预注册：stale-state error、memory reconstruction error、unseen-state robustness、invalid-action recovery。

### 资源阶梯

- **零 GPU construct gate：** 验证 text provenance 的变化没有偷偷改变可恢复环境信息；验证 state occupancy 差异不是单纯 difficulty 差异。
- **8 卡 smoke test：** 1–1.7B student、一个环境、单 seed、四格各 30–50 updates；约 3–6 小时 wall time。只用于看 effect sign 和实验是否可跑。
- **8 卡 kill test：** 两环境、3 seeds；约 18–30 小时 wall time，144–240 A100-hours。
- **32 卡 full scale：** 只有 kill test 通过后，扩到更大 agent、三环境；约 800–1,440 A100-hours。

### Go / stop

**Go：** 两环境、3 seeds 上至少一个预注册 main effect 或 interaction ≥5 success points，95% CI 不跨 0，并使对应 failure class 相对下降 ≥20%。

**Stop：** textual provenance 无法在不改变有效 memory state 的情况下操纵；或所有效应 <2 points / 跨环境变号。

### 最强反对理由

rationale/text 本身就是 agent effective state 的一部分，因此所谓两条轴可能根本不正交。若 construct audit 过不了，整篇论文在训练前就应停止。

## Rank 2 — C02: Compositional Closure Boundary

### 一句话 thesis

在有限、可审计的 reasoning world 中，student 已掌握 A 与 B，却在部署相关概率边界下不会 A∘B；same-origin OPD 能把它推过组合闭包边界，并把该组合算子迁移到语义同构但符号重命名的域。

### 为什么它比“OPD 提高已有路径概率”更强

[Test-Time Scaling OPD](https://arxiv.org/abs/2608.11829) 的重要结论是 OPD 更像提升 sampling efficiency，而非扩展 capability boundary；[RL compositional strategies](https://arxiv.org/abs/2607.07646) 则展示 RL 可形成组合 procedure。C02 的 paper claim 是把两者正面接起来：在能审计 primitive 与 composition 的世界里，OPD 是否真的跨越 operational closure boundary。

### 关键设计

构造 constrained rewrite / small-program world：

1. A、B primitive 的正确率均 ≥95%。
2. 有限 action grammar 和 bounded horizon 允许精确枚举，或给 composition success mass 一个校准上界。
3. teacher 与 student same-origin；teacher 掌握 A∘B。
4. OPD 后同时测原域与随机符号置换的同构域。
5. baseline 包括等算力 RL、SFT、只增加 resampling，以及 teacher-output imitation。

### 资源阶梯

- **零/低 GPU construct gate：** 先在小 action space 上证明能算 total success mass，而不是只报 pass@K。
- **8 卡 smoke test：** 0.6–1.7B、单 grammar、单 seed；约 4–8 小时。
- **8 卡 kill test：** 3 seeds + isomorphic domain + matched baselines；约 10–20 小时，80–160 A100-hours。
- **32 卡 full scale：** 多 grammar、多 family；约 480–960 A100-hours。

### Go / stop

**Go：** pre-OPD composition mass <10^-6；post-OPD 原域 >20%、同构域 >15%；primitive accuracy 变化 <2 points；resampling-only <5%。

**Stop：** pre-OPD rare mass 足以解释增益；同构域不迁移；结果依赖一种 surface encoding；或无法精确审计，只剩“有限 K 没采到”。

### 最强反对理由

softmax LM 几乎对所有合法 token sequence 都给正概率，因此不能声称数学意义的 zero support。论文必须说 operational boundary，并预注册阈值；否则只是把 ultra-rare amplification 改名为 acquisition。

## Rank 3 — C16: Causal Content of Teacher Rationales

### 一句话 thesis

当 final answer、长度、格式、operator counts 与可检测表面统计都匹配时，teacher rationale 的逻辑有效性——而不是 fluent rationale text——决定 OPD 后的 counterfactual transfer。

### 与已有工作的差别

[Self-Distilled Reasoner](https://arxiv.org/abs/2601.18734) 和 [One Student, Many Teachers](https://arxiv.org/abs/2607.18293) 让 privileged-context teacher / rationale 进入 on-policy distillation，也暴露 post-hoc rationalization 风险；CoT faithfulness 文献多是在测试模型自己的 rationale 是否影响答案。C16 要做的是随机化监督实验：只改变 teacher rationale 的 formal validity，然后观察 student 学到了什么。

### 最小实验

在两个机械可验证的 formal task families 上，为每题生成三联体：

- valid proof；
- answer-conditioned fluent rationalization；
- 只有一个受控 invalid step 的 trace。

匹配 final answer、长度、格式、operator multiset 和尽可能多的局部 likelihood 特征；用一个看不到标签的 classifier 检查条件是否可被表面特征识别。然后等预算训练，测试专门破坏 shortcut 的 counterfactual variants。

### 资源阶梯

- **零 GPU construct gate：** mechanical checker 必须判定逻辑有效性；surface classifier 不应轻易识别三种条件。
- **8 卡 smoke test：** 1–1.7B、一个 formal family、单 seed；约 3–6 小时。
- **8 卡 kill test：** 两 task families、3 seeds；约 12–22 小时，96–176 A100-hours。
- **32 卡 full scale：** 自然语言任务与更大 student；约 576–1,120 A100-hours。

### Go / stop

**Go：** valid condition 相对两种 control 的 counterfactual accuracy ≥5 points，且 IID answer accuracy 差异 ≤1 point；或得到有足够 power 的 ±2 points 等价性结论，同时匹配 classifier ≤55%。

**Stop：** 条件 identity 的 surface classifier >65%；invalid traces 改变 supervised-answer correctness；第二个 formal family 不复现；或只有 LLM judge 支持 validity 标签。

### 最强反对理由

“有效推导优于错误推导”本身完全不惊讶。只有在三联体真的匹配、IID 结果相同而 counterfactual transfer 分离时，才有顶会级因果发现。

## Rank 4 — C12: Capability Identifiability from Prompt Support

### 一句话 thesis

标准 in-support OPD 结果不能识别究竟转移了哪个 latent capability：若两个 prompt supports 的可见训练摘要匹配，它们可产生相同 IID performance，却在 primitive recombination intervention 上显著分叉。

### 最小构造

在 procedural task 中生成两套 supports，匹配 prompt length、answer distribution、difficulty、primitive marginals、student reward、teacher entropy 与 IID accuracy，但改变 primitive co-occurrence。对两套 support 和 union 分别做同配方 OPD，评估 held-out recombination 与 nuisance-inverted prompts。

### 资源阶梯

- **零 GPU gate：** 明确只是 matched observable summaries，而不是不可能的“完整训练分布完全相同”。
- **8 卡 smoke test：** 单 generator、单 seed；约 2–5 小时。
- **8 卡 kill test：** 3 seeds；约 8–16 小时，64–128 A100-hours。
- **32 卡 full scale：** 多 task generators 与 model families；约 384–768 A100-hours。

### Go / stop

**Go：** 两个 single-support students 的 IID 差异 ≤1 point，但 recombination 差异 ≥10 points；union 至少闭合一半 gap；仅用 matched surface statistics 的 classifier 对 support identity ≤55%。

**Stop：** surface differences 足以解释 gap；SFT/outcome-only 产生完全相同模式、没有 OPD interaction；union 不修复；或“equivalence”只依赖事后挑选的几项指标。

### 最强反对理由

如果完整观察分布真的相同，学习分布就不应不同；如果只是几个摘要相同，这可能只是普通 dataset underspecification。论文必须证明 OPD-specific interaction，而非重新发现数据共现结构很重要。

## 第二梯队

### C22 — OPD Future Plasticity Trajectory

值得保留。问题是：当前 benchmark matched 的 OPD、RL、offline-KD checkpoints，未来学习新任务的 adaptation curves 是否不同，且 OPD 中间 checkpoint 是否比最终 checkpoint 更可塑。它与 stability–plasticity 和 intermediate-checkpoint utility 相邻，但尚未看到直接覆盖 OPD lifecycle 的工作。

**暂不进前四的原因：** performance matching 不控制参数距离、entropy、optimizer state、训练总 compute 与剩余 LR budget；若这些 covariates 控制不住，所谓 future plasticity 峰值不可归因。

### C23 — Knowledge–Reasoning Order Composition

比较固定 token multiset 下的 domain CPT→OPD、OPD→CPT 与 interleaving，估计非交换 interaction。空间仍有，但 [Front-Loading Reasoning](https://arxiv.org/abs/2510.03264) 及 pre/mid/post-training interaction 文献很近。

**暂不进前四的原因：** 若观察只是“后训练覆盖前训练”，就是普通 catastrophic forgetting；必须出现超出 additive forgetting 的 synergy/antagonism。

## 为什么 C07 没进榜

`Non-Commutative Multi-Teacher OPD` 是本轮最漂亮的数学叙事之一：测 `A→B` 与 `B→A` commutator，再用 `A/2→B→A/2` 消除一阶顺序误差。但 [Continual Distillation](https://openreview.net/forum?id=FDKI0KU7Dc)、[Open-MOPD](https://arxiv.org/abs/2608.19098) 与 Counteraction-Aware MOPD 已覆盖 sequential teachers、capability imbalance 与 alternating counteraction。

所以它当前只能 Park：**除非 1–5 个 short updates 得到的 local commutator 能跨 teacher/domain pairs 定量预测长程 retention/interference。** 仅证明 AB≠BA 或 palindromic schedule 更好，容易被评为 continual learning + operator splitting。
