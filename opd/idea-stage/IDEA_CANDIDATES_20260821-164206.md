## Candidate definitions

### C01 — Rare-Event Capability Frontier

用 importance sampling / splitting 等 rare-event estimation 对正确轨迹的极低概率质量给置信界，区分“support 真消失”和“固定 K 没采到”。如果只有 decoder sweep 或大 K，则与上一轮 C01 及 test-time-scaling 工作重复。

### C02 — Compositional Closure Boundary

在完全可审计的 rewrite/program world 中，让 base 明确掌握原子算子 A、B，却在 exhaustive 或有证明的条件下缺少组合算子 A∘B；再检验 same-origin OPD 是否真正获得组合闭包，并把算子迁移到表面重编码的同构域。

### C03 — Origin–Behavior Compatibility Factorial

用 `same/cross ancestry × matched/mismatched reasoning dialect` 的 2×2 干预分离 ancestry 与行为兼容性。它与上一轮 `Matched-Delta Causal Control` 近重复，本轮不当作新推荐。

### C04 — Teacher Acquisition-Path Dependence

构造 endpoint 尽可能匹配、但分别由 SFT demonstrations 与 RL search 获得同一能力的 teachers；在同一 student states 上进行 OPD，检验 teacher endpoint 是否是 distillability 的充分统计量。

### C05 — Branch-Extinction Phase Transition

在具有精确 branch identity 的形式推理任务上密集保存 OPD checkpoint，追踪每个有效 reasoning branch 的概率和消失时间，检验 rare branch 是否在平均准确率平台前出现可复现的临界消失。

### C06 — Correct Marginals, Wrong Reasoning Modes

构造只匹配有限窗口统计、但长程 strategy correlation 不同的 teacher distributions，证明 token-local OPD 无法保持 coherent modes。必须明确不是“完整条件分布相同但 joint 不同”这一数学上不可能的表述。

### C07 — Non-Commutative Multi-Teacher OPD

把两个 teacher 的短 OPD 更新视为 policy flows，测量 `A→B` 与 `B→A` 的行为 commutator；检验短步 commutator 是否预测长程 capability interference，并用 palindromic `A/2→B→A/2` 调度抵消一阶顺序误差。

### C08 — Capability-Mass Accounting

定义互斥且可审计的旧成功、新成功、共享成功与失败 sequence sets，估计 OPD 前后概率质量迁移，检验 target gain 是否可预测 rare old-capability loss。只有跨 scale held-out prediction 成立时才称为 law。

### C09 — Search-to-Circuit Conversion

在有限算法世界中检验普通 OPD 是否会把 base 只能通过稀有 search 找到的过程编译成稳定、可因果干预的内部 algorithm，而不是只提高表面答案频率。

### C10 — Symmetry Breaking / Equivariance

利用任意符号重命名等精确 task symmetry 测量 OPD 前后的 equivariance；观察 teacher 的微小非对称是否被放大成 rare-mode loss。只能作为 OPD-specific amplification finding，不能宣称首个 symmetry distillation。

### C11 — Teacher Conditional-Invariance Factorial

在语义状态不变时独立改变 serialization、length、distractor 与 tokenization，测量 teacher target 与 OPD transfer 是否遵循共同 invariance principle。

### C12 — Capability Identifiability from Prompt Support

构造训练可见统计观察等价、但 latent primitive coverage 不同的 prompt supports；证明普通 in-support accuracy 不能识别“转移了什么能力”，再用 intervention/recombination test 区分。

### C13 — Semantic Alignment Destruction Test

在匹配 task、length、entropy、overlap 与训练步的条件下打乱 teacher targets 与 prefixes 的语义配对，作为 OPD 机制实验的 randomized negative control。

### C14 — Two Axes of On-Policy for Agents

分别操纵环境状态 occupancy（student/teacher visited）与 textual rationale provenance（student/teacher generated），做 2×2 factorial，区分 exposure-bias reduction 到底来自哪条轴。

### C15 — Interventional Response-Surface OPD

匹配 teacher 在 premise/tool/subgoal 干预下的 effect vectors，而非绝对 token conditional。因 causal KD/Jacobian matching/CROP 先例强，只能保留极受控的 generative reasoning finding。

### C16 — Causal Content of Teacher Rationales

在 formal tasks 上机械生成答案、长度、风格和局部似然尽量匹配的 valid、post-hoc、single-invalid-step rationales，随机分配监督，检验 OPD 真正吸收的是推导因果内容还是 fluent rationale regularization。

### C17 — Teacher Identity as Missing Policy Variable

把多 teacher 目标视为以 teacher identity 为条件的 policy，比较 identity-conditioned 与 marginalized training，用作诊断 multi-teacher seesaw 的因果干预，而不是新 MoE architecture。

### C18 — Critical Period for OPD

在不同 pretraining checkpoints 插入完全相同的 OPD pulse，再让所有分支继续相同 future token stream；只在出现 OPD-specific 的 persistence/reversal/nonmonotonic window 时成立。

### C19 — Capability Homotopy Teacher Ladder

弱→中→强 teacher ladder。与 teacher assistant、Pro-KD、progressive distillation 直接重复，淘汰。

### C20 — Evolving-Teacher Tracking Transition

固定 teacher checkpoint multiset，只改变 slow/abrupt/shuffled/reverse order，估计 teacher drift rate 与 student adaptation time 的 phase boundary。

### C21 — Generational Half-Life of OPD

递归执行 teacher→student→下一代 teacher，测量不同 reasoning capabilities 的选择性半衰期；generic decay 不是 novelty，只有结构化消失顺序或先升后降现象有空间。

### C22 — OPD Future Plasticity Trajectory

从 dense OPD checkpoints 中构造当前能力匹配的 OPD/RL/offline-KD checkpoints，对全新 downstream skills 画完整 adaptation curves，检验当前最优 checkpoint 是否反而不是未来最可塑 checkpoint。

### C23 — Knowledge–Reasoning Order Composition

严格匹配 token multiset，比较 domain CPT→OPD、OPD→domain CPT 与 interleaving；用 joint knowledge×reasoning tasks 估计非交换 interaction，而不是只报告普通 catastrophic forgetting。

### C24 — Temporal Resonance in Cyclic Multi-Domain OPD

固定 A/B 总 exposure，仅改变 cycle period，检验最佳 period 是否与 rare-skill decay time 形成跨域稳定的无量纲关系。已有 cyclic distillation 先例，风险高。

### C25 — Origin–Scale Phase Diagram

same/cross origin × student scale。最新工作已做 1.5B/7B origin grid；仅添加 3B 点不新，淘汰。
