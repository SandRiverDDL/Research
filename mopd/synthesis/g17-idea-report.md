## 已有证据允许我们提出什么

**【作者报告／原文核对】** “利用互补 teachers”已有大量覆盖。Trust 已有位置分配和组合训练，H-OPD 有异质信息桥接，SMOPD 有同 prompt 的多目标整合，MAD-OPD 有 teacher 交互监督。因此本报告不声称现有方法只能分域选择。TU-OPD 的整题可靠性筛选限定了它能直接使用的训练样本，但不能把这一限制外推到 Trust 等方法。

**【解释】** 超过 best teacher、恢复各域平均分、增加可解题 union 都不足以单独证明同题联合使用。最有意义的测试要求：正确完成前段并不足够，后段必须正确使用前段产生的信息或选择；模型凭固定模板或绕过其中一个专长不能解题。

**【待验证假设】** 当前没有证据表明“局部聚合普遍丢失组合能力”。候选分别检验局部可信知识是否不足以组成完整教学、重要中间状态是否稀缺、已有条件监督是否在有限训练中未高效传递关系。容量不足也是竞争解释，不能被排除在外。

## 2026-10-15历史推荐（已撤回）

### 首选候选：跨步骤交叉比蒸馏（L3-A2）

**先看方法。**

1. 让 student 对同题生成两条轨迹，找出两个有效的前段选择，以及与之对应的两个后续片段。例如，前段选择不同单位或变量表示，后段必须随之改变计算。
2. 请后续专长 teacher 对“两个前段 × 两个后续”的四种搭配评分，得到它对正确搭配与错配的条件偏好；只做强制评分，不为四种搭配生成完整 rollout。
3. 在普通 MOPD 外，让 student 匹配“前段改变后，后续偏好改变了多少”。所有对照也获得同样四格数据和评分。部署仍只有 student。

**【候选公式】** 令 s_M(i,j)=log P_M(v_j|p_i)，Δ_M=s_M(1,1)+s_M(2,2)−s_M(1,2)−s_M(2,1)。原候选增加 λ(Δ_student−clip(Δ_teacher))²。它消去可分离的行列加性偏置；这不是因果效应，也不保证移除所有风格或长度偏差。

**【待验证主张】** 当 A 的选择决定 B 应如何继续时，显式教“条件偏好的变化”能比同数据普通 KD 更有效地形成联合能力。完整历史的 token 模型本来就能表达这种关系；贡献只能来自有限预算下的学习效率和泛化，而非表示能力的不可能性。

**查新结果：PROCEED，6/10，暂定。** [RouteOPD §3](https://arxiv.org/html/2609.08337v1#S3) 已做同一个状态中词表项的 pairwise log-odds；[RKD §3.2](https://arxiv.org/pdf/1904.05068) 已做关系蒸馏；[ANT](https://ojs.aaai.org/index.php/AAAI/article/view/26190/25962) 已做 partial teachers 的依赖传递。剩余差异是**两个不同前缀之间的条件偏好变化**，不能把“关系蒸馏”本身当新颖性。

**最便宜的证伪。** 先整理约128组可执行的四格搭配，检验 teacher 的关系分数是否对应真实的执行依赖；再比较同数据普通 KD、sequence preference 与该目标，并打乱搭配检验机制。若同数据 KD 达到同样联合成功，或打乱搭配不损失效果，则方法主张不成立。普通 MOPD、RouteOPD 和更大 student 是后续必要对照。

**关键风险。** 后续 expert 在自然搭配上可靠，不等于在交叉搭配上也可靠。分别截断多个重叠关系还可能让目标互相矛盾：若 D12=D23=0.8c，则原本 D13=1.6c；分别截断后 D13=c，却不等于前两项之和。原候选尚未解决此问题，不能宣称目标一定可共同实现。另须证明前段 teacher 确实必要，否则这只是单 teacher 也适用的关系监督。

**开销与价值。** 原设想2000题中仅10%形成配对、片段≤128 token，复用自然搭配评分后新增约5.12万 teacher 续写评分 token；这不含前缀重算、student 交叉评分、配对校验和更新成本。无额外 teacher rollout，易做同预算比较。若上述控制后仍改善未见组合，才有机会成为清楚的方法贡献。风险：MEDIUM；pilot：未运行。

### 第二候选：认证具体局部动作，再联合蒸馏（L1-A1）

**先看方法。**

1. student 自己生成轨迹，每条只选一个实际访问的前缀；不同 specialists 各给一条短结论或纠正，并附检查器能够验证的证书，不要求任何一位给出完整解。
2. 检查器根据原始题设验证这些具体动作；它检查给定证据，不搜索答案。把通过验证的有限动作集合交给 student 学习。
3. 下一轮仍由 student 独立生成，在它实际遇到的状态上继续教学。最终去掉 teachers；不同专长提供的必要步骤由一个 student 执行。

**【候选公式】** 在本轮生成、去重并认证的有限集合 C(s) 上，q(c|s)∝1[c∈C(s)]Σ_i p_i(c|s)，最小化块级 KL(q‖π)。集合为空则跳过。不能把 C(s) 解释为所有合法动作的免费枚举；teacher 生成块中的后续 token 是强制输入，因此这是 student 访问状态上的块级混合蒸馏。

**【待验证主张】** 整题可靠性不高的 specialists 仍可能提供互补、有用、可认证的局部知识；把这些知识送到 student 当前状态，可以教出任一单 teacher 不稳定掌握的联合解法。

**查新结果：PROCEED，6/10，暂定。** [VG-OPD §3.2–3.4](https://arxiv.org/html/2609.15404v2#S3) 已按 criterion 许可专家，不能声称它需要整题赢家。[Process-Verified RL §3–4](https://arxiv.org/html/2606.20068) 已用 Lean 的 tactic 检查提供过程奖励。这里剩余的差异是**在 student 真实状态上，认证将要蒸馏的具体动作，并由不同 experts 提供这些动作**；不是泛称“局部验证”或“不要完整答案”。

**最便宜的证伪。** 先用32道已有形式证明题做信号审计：两个 teachers 的认证动作并集，是否比最佳单 teacher 新增能接向目标的有用步骤？已知证明只供审计，不能传给教师。先统计非法前缀、无关真命题和无新增知识的比例。若没有新增有用动作，就不值得进入训练。若有，再与同一认证数据的离线 SFT、同预算过程 RL、VG-OPD 和普通动态 MOPD 比较。

**关键风险。** “正确”不等于“有帮助”：重复题设、恒真结论和冗余步骤都可能过验证。局部动作并集也不保证存在可学习的完整路径。student 错误前缀如何对应合法证明状态尚未定义；检查器不能偷偷承担修复和规划。若最终只有多来源认证 SFT 的效果，就不足以支撑独立的新方法。

**开销与价值。** 原设想2万条 student 轨迹，每条仅查询一次、每 teacher 最多128 token，约512万 teacher 生成 token、最多4万次证书检查；候选交叉评分、前缀读取和 teacher 制备另计。适合先在已有形式环境判定信息是否足够，再评估规模化。若能稳定利用“整题弱、局部强”的专家提供有用知识，研究问题清楚；自然任务上的证书可得性仍开放。风险：MEDIUM，含高影响的状态与进展风险；pilot：未运行。

### 高风险储备：按 student 真正学会多少来训练 teachers（L1-A4）

**先看方法。**

1. 两位专长 teacher 对同一个 student 前缀各给一段短提示；当前 student 的冻结副本读两份提示，产生蒸馏目标。实际 student 不看提示，只学习该目标。
2. 用小批量监督临时更新 student 一步，再在独立联合题上测它不看提示时的表现变化。
3. 把这份真实学习增益作为两个 teacher 消息策略的共同奖励，更新它们的 LoRA；交替训练，最后只部署无提示 student。

**【待验证主张】** 与只优化 teachers 自身解题率相比，直接优化它们共同造成的 student 学习增益，可能得到更可吸收的互补消息。中心目标为 R=Acc_V(θ′)−Acc_V(θ)，而非 student 还看着提示时的答对率。

**查新结果：PROCEED WITH CAUTION，4.5/10，暂定。** [IKD 的 Course/Exam Step](https://arxiv.org/html/2109.04641) 已用 student 一步更新后的独立 exam loss 优化 teacher；[MMKD §III](https://arxiv.org/html/2306.06634) 已据 student 学习效果元优化多 teacher 聚合。剩余差异仅是**直接训练多个生成式 teacher 的局部消息策略**，要用结果证明这比学习权重或固定消息有价值。不能把“以 student 增益训练 teacher”称为首创。[Assistance Dilemma §3](https://arxiv.org/html/2610.06446) 的 student 参数冻结、通过上下文学习，不等同于这里的参数更新。

**最便宜的证伪。** 先不训练消息策略：从同一个 student 起点，比较少量不同提示造成的一步更新效果，并重复同一提示估计噪声。若提示间无提示教学增益的差异小于重复噪声，元奖励没有可用信号，就停止。若有，再与固定消息、同 token 数的单 teacher 提示、MMKD 式加权及把额外预算用于 student RL 比较。

**关键风险。** 原方案每次只用16题、前后各一次采样，独立伯努利估计的最坏标准误约0.177；这可能远大于一步更新的真实收益。共同奖励也不保证互补：一位 teacher 可以搭便车。短提示可能已经编码完整答案，且持续复用元验证集会过拟合。

**开销与价值。** 原方案64轮×4次试验的前后评测约增加419万生成 token，另有临时更新、提示生成、条件 student 副本评分和 teacher 制备。统计功效未确定，不能保证这些调用足够。它的潜在价值是把“怎样共同教会 student”变成可优化的教师制备目标；当前代价与前作重合都较高，排在前两项之后。风险：HIGH；pilot：未运行。

## 最小验证边界

这些是决定是否继续投入的检查，不是已运行实验或完整实验计划。

1. **先确认题目确实需要联合使用。** 同一题同时检验两种专长及二者之间的依赖；分别测 A、B 单项表现与整题联合成功。拆掉任一必要信息或交换早期决定后，后续正确行为应改变。不能仅把两个互不影响的独立题拼在一起。
2. **确认 teacher 池里有可转移的信息。** 在具体中间状态上检验局部可靠性；“抽样没有成功”不等于 teacher 永远不能整题成功，必须报告样本数和不确定性。检查器只验证已给定结果，不把寻找完整解当免费服务。
3. **排除相同数据就够了。** 所有方法拿到相同样本、交叉评分、证书或提示，比较普通 KD、适用的动态 MOPD、同预算 RL/离线训练。若收益完全由新增数据或评分解释，不能归因于新目标。
4. **区分方法、容量与预算。** 保持相同 teacher 池，同时加最佳单 teacher／合并专长数据的单 teacher、更大 student 的对照。计入 teacher 制备、额外上下文、验证、生成和评分；不把未测速的 token 数写成 GPU 小时。

评价以原始输入、无 teacher 辅助部署下的整题联合成功为主，同时报告单项能力、覆盖率与关键状态到达率。关系匹配误差、通过检查的局部动作数、提示下的正确率都只是诊断量，不能替代部署结果。先用结构清楚的小任务排除机制，再决定是否扩到自然任务；只在受控合成任务上成功不足以支撑广泛 LLM 能力整合的主张。
